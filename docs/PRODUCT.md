# 云猫岛完整产品需求与交付状态

## 不变原则
只做猫；不引入狗、强制签到、战斗、猫咪语言聊天。手机网页免注册登岛，猫咪自主生活，多人共享为目标。

## 规划功能域
1. 猫咪生态：模型、骨骼动画、个体身份、行为、群体关系、导航与环境互动。
2. 岛屿生态：地形、海滩、树林、建筑、昼夜、天气、空间音效。
3. 游客：移动、镜头、轻互动、无障碍与触控。
4. 多人：身份、同步、房间、断线恢复、权威猫咪状态、反滥用。
5. 留存：猫咪图鉴、发现、拍照、匿名本地进度、可选跨设备账户。
6. 增长：分享、邀请、活动；运营分析及隐私说明。
7. 平台：Cloudflare 部署、CI、告警、成本监控、回滚。
8. 商业化：仅在验证后评估，免费基础登岛不变。

## 交付边界
已实现：轻量 3D 原型、基本猫咪行为、手机摇杆、可旋转镜头、猫咪身份；本次增加图鉴、浏览器本地记录、截图、可选交互提示音、天气视觉切换。
未完成：真实授权猫模型与骨骼动画、自然地形与寻路、正式多人联机、跨设备账户、后台运营、生产监控与大规模压测。不要把规划写成已上线。

## 验收
每次提交应通过 GitHub Actions 的 node --test、语法检查与 Vite 构建；Cloudflare 实际部署状态另行核实。手机真机与多人压测需独立验收。
