# 架构记录 ADR-001

## 当前状态
Vite + Three.js 单人前端原型，静态部署可行，但未部署。猫咪与游客状态均在本地内存，当前没有多人同步。

## 计划
- 静态前端：Cloudflare Pages
- 多人服务：Workers + Durable Objects，WebSocket 分房
- 猫咪状态：服务端权威，客户端插值显示
- 可靠性：房间人数上限、心跳、消息大小限制、断线重连、速率限制
- 数据：匿名事件统计，不收集个人身份信息；上线前补充隐私声明

## 成本与性能
首版限制同时在线人数和同步频率，先压测再开放。避免未核实的免费额度假设。

## 发布门禁
CI 通过、手机/桌面手测、多人压测、监控与回滚方案齐备后才可宣布上线。
