# 云猫岛写实视觉升级：实施规范

## 视觉验收
- 真正的猫咪解剖比例、眼睛、胡须、PBR 毛发纹理、自然色差；不接受基础球体/圆柱猫作为正式资源。
- 优先表现睡觉、缓慢呼吸、舔毛、伸懒腰、自然步态和停顿。
- 手机端镜头支持近距离观察；HUD 不遮挡猫咪脸部。
- 场景以自然海岛为主，降低纯色几何植被和玩具感。

## 工程实现
- src/realistic-cat.js：GLTFLoader、缓存、统一高度、骨骼动画选择及平滑切换。
- public/models/cats/manifest.json：只允许登记经过许可证核实且已经上传的同源模型。
- 加载失败时保留原占位猫，避免白屏。该降级行为只用于开发和故障恢复，不计入写实验收。
- 不从第三方跨域 CDN 热链模型，不依赖每次页面打开时访问第三方网站。
- 模型材质、动画和许可必须逐项验收，避免将低多边形模型当作写实资源。

## 当前阻塞
模型文件尚未获得和上传。代码已经建立替换接口，但生产站的猫咪仍是占位模型。正式写实交付需要实际 GLB 二进制、授权证明和移动端性能验证。
