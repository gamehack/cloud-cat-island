# 写实猫咪资产目录

正式资产须置于此目录，文件名与 manifest.json 一致。GLB 须包含商业使用许可、作者、原始 URL、下载日期与许可证快照；不得直接复制未核实授权的 Sketchfab 或付费模型。

建议每个猫模型提供 idle / walk / sleep / groom / sit 骨骼动画，并采用 glTF 2.0 + PBR。移动端优先：目标单模型压缩后小于 5MB、纹理优先 1K、合理 LOD。

当前没有已验证可商用且具备写实毛发与自然动画的模型二进制文件，因此 manifest.json 的路径不会被启用。不得将程序化几何体称为写实猫咪。

候选：Innerscene Standing Cat CC0（静态无骨骼，不满足最终验收）；Vuena Cute Pets CC0（有动画但玩具风格，不满足写实验收）。仅作为技术调查参考。
